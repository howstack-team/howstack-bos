- 禁止将协议模拟、临时签名密钥或后台线下充值当作真实商户收款证据。

## 本轮落地

1. 修复微信Native加载阻断：宿主URI Template原为2.0.1，与微信SDK1.5.0要求不一致；宿主固定为双方兼容、与插件一致的1.0.11。不放宽插件SDK冲突校验，不改历史支付快照及商户配置。
2. 增加只读 `payment:check [后台支付ID] --json`：验证配置前置条件、支付与原充值一致、单次入账及来源/账户守恒。发现差错只输出失败，不自动补账，也不调用任何支付平台接口。
3. 区分本地与外部结论：报告始终标记真实验收待完成、公网回调和商户账单未测试。退出码0仅表示本地准备检查通过。
4. 移动收银明确扫码方式；本页不直接唤起支付应用。二维码下载通过Chromium模拟设备验证，真机及支付应用识别仍待验收。
5. 保留现有幂等、签名验签、原通道快照、查单/关单、未知结果与唯一入账策略。
