## 1. 本轮范围与状态

本轮优先建设运营后台。会员控制台、门户主题、购买页面和结算页面暂缓。

**当前实现**：固定云服务器工作台（十个区域）、配置资源、网络策略、外部平台交付规则、销售草稿、不可变销售版本、配置联动、整数费用预览、供应连接、魔方云 v1 登录及目录读取、资源映射和细粒度权限。

**后续建设**：有效报价记录、订单创建、真实收款、履约任务、开通与续费、试用办理、资源释放与退款执行和上下游采购。已实现分类供应插件、公共 SDK v1 与本地安装管理；后台的“已发布 / 启用”表示配置管理状态，不能据此宣称真实购买链路已可售。

[云服务器工作台方案](../architecture/cloud-server-workspace-plan.md)的首批后台整改已经落地：产品身份固定，销售方案独立维护，产品类型列和产品新增入口已移除。多来源自动选择、同系统上游采购和真实生产仍按后续阶段建设。

## 2. 页面组织

“产品管理 → 云服务器”的入口为 `/admin/products/cloud-servers`，直接显示十个 Tab：概览、地域、可用区、线路、规格、镜像、存储、网络、销售方案和交付规则。位置保存为 `?tab=...`，刷新、前进和返回保持位置；未知或无权区域回到有权限的首个区域。

规格组在规格中维护，镜像分类在镜像中维护，网络策略和防护在网络中维护。销售方案可以新增；没有产品列表、新增产品或产品类型配置。

供应连接同样位于“产品管理”下，路径保留 `/admin/providers/connections`。它由各产品类型共享，在独立页面维护连接和映射，避免重复配置。

### 云服务器配置资源

按地域、可用区、线路、规格组、规格、镜像分类、镜像、存储类型、防护和网络策略组织资源。可用区归属一个地域；线路、规格、镜像和存储类型通过独立关系表关联多个可用区，防护可以关联多条线路。规格归属一个规格组，镜像归属一个分类，父级均可以包含多个子项。资源保留内部稳定标识、启停、排序及描述。排序只用于维护和展示顺序，不占表格列。

规格明确 CPU 核数、内存 MiB 和架构；规格组可填写 CPU 型号、主频及睿频（整数 MHz，选填）。镜像维护最低 CPU、内存、系统盘要求及架构、登录方式，在选项解析、发布和计价时验证。存储类型可填写读取/写入 MB/s 和 IOPS（选填，仅描述能力，不承诺监控或性能保证），同时维护容量边界、步长和数据盘数量。型号及存储等周期默认价为整数分。网络策略维护带宽与 IPv4 的能力范围和步长，售价仍在销售方案中设置。引用策略的销售方案只能缩小范围，发布时验证范围和步长。

### 销售配置

专属表单分为基本信息、部署与计算、镜像与存储、网络与防护、周期与价格、试用与售后。销售方案选取可售资源、设置价格覆盖及政策，不修改供应目录。允许保存未完成草稿。

发布要求可售资源完整、关联与架构兼容、有可交付的系统盘容量、周期价格完整，并绑定已测试且启用的供应连接和已读取的外部目录。发布不会自动启用。相同内容重复发布不会新增版本。

发布版本封存固定产品身份、方案名称、资源、价格、政策、契约版本和供应映射；引用交付规则时同时封存规则标识和 revision。规则停用或线路范围不匹配时拒绝新发布，发布时锁定规则，历史版本继续保留原规则。每份方案当前明确选择一条外部平台交付规则；也保留旧草稿直接选择供应商的兼容路径。后续改价、停用资源或修改草稿，不改变既有版本。预览可指定版本 ID，服务端验证版本归属。

试用、退款和自动续费字段在本轮仅保存政策，不触发业务执行。

### 后台预览

服务端按当前选择解析地域、可用区、线路、规格、镜像和存储选项。地域或可用区改变后，前端清理失效选择；服务端在计价时再次验证。

每台费用为：计算规格＋max(0, 系统盘容量－赠送容量) GiB×单价＋各数据盘 GiB×单价＋带宽费用＋IP 数量×单价＋可选防护＋一次性费用，再乘购买数量。检查镜像架构及最低 CPU/内存/系统盘、磁盘步长、磁盘数量、网络范围、登录方式和周期。

销售方案的“镜像与存储”提供 `system_disk_included_gib`（系统盘赠送容量，0–65536 GiB 的整数，默认 0）。按每台实例、每个所选预付费周期独立赠送，未用完不转入数据盘或抵扣其他费用。例如赠送 40 GiB、选择 60 GiB，系统盘仅按 20 GiB 收费；购买两台则每台分别计算。完整容量仍受镜像最低要求及存储范围、步长限制，交付参数仍为 60 GiB。赠送政策随销售版本封存，修改草稿不改变历史快照；旧草稿及旧快照缺省为 0，保留原费用。该字段保存在已有校验 JSON 中，无需新增数据库字段或改写历史数据。

带宽支持固定单价 `flat`、按区间累进 `graduated` 和按整段单价 `volume`。阶梯上限包含边界，从 0 开始连续计费，只有最后一段可留空上限；边界必须严格递增，价格覆盖最大可售带宽及全部可售周期。例如前 5 Mbps 每 Mbps 100 分，超过部分 80 分：10 Mbps 累进为 900 分、整段为 800 分。全部计算使用整数分，阶梯进入发布版本，不随当前价格修改而变化。

“校验交付配置”通过 `mode=delivery` 验证完整选择和供应对应关系，并输出资源外部编号、CPU/内存、各块磁盘容量、带宽、IP 数量及登录方式。该预览不发送外部请求，不接收密码、私钥或生产凭据；供应插件后续将标准配置转换成自身 API 参数。未保存交付预览资料的旧版本继续支持原费用预览，交付预览需使用新发布版本。

预览不保存报价、不锁定供应、不创建订单，不接收密码或私钥。后续结算需要重新校验并生成有有效期的正式报价。

## 3. 模块与持久化边界

| 模块 | 责任 |
|---|---|
| `compute` | 类型专属资源模型、联动、组合校验和配置计价 |
| `product` | 产品身份、销售草稿、版本发布、后台管理与预览编排 |
| `provider` | 连接凭据、外部目录、资源映射、绑定封存及适配器调用 |

仓储使用模块内 `support\Model` 模型。Application 和 Domain 不依赖 ORM；跨模块供应绑定通过 Contract 写入，与销售版本处于同一数据库事务。草稿及连接使用 revision 拒绝过期写入。

新增迁移 `20261002000100_create_cloud_commerce.php` 创建 16 张表，`20261002000200_expand_cloud_configuration_storage.php` 扩展销售草稿、版本快照和绑定映射的文本容量，`20261002000300_expand_provider_configuration_storage.php` 扩展加密插件配置及能力快照容量，避免普通 TEXT 的 64 KiB 限制。不修改现有订单、资金和服务表。采用前向升级，保留客户数据及自定义表前缀。

新增前向迁移 `20261003000100_create_cloud_server_workspace.php`：创建固定云服务器身份，将旧产品描述回填到各销售方案，保留旧产品记录和全部版本/摘要，将当前方案关联到固定产品，移除产品表的 `product_type` 字段；新增网络策略及交付规则表。固定身份由迁移建立，普通查询不写库；订单、资金和服务表保持原结构。

新增 `20261003000200_expand_cloud_resource_configuration.php`：为五类可复用关系创建关系表，回填旧主关联；增加硬件参数、镜像最低 CPU/内存、交付规则资源范围以及供应映射的可用区作用域。旧 `zone_id/line_id` 保留为兼容主关联，新界面使用 `zone_ids/line_ids`。迁移可重复执行，不修改历史销售快照、绑定或资金表。

新配置见 [云服务器 v1.3 契约](../../contracts/products/cloud-server.v1.3.schema.json)，旧 [v1.2](../../contracts/products/cloud-server.v1.2.schema.json)、[v1.1](../../contracts/products/cloud-server.v1.1.schema.json)、[v1.0](../../contracts/products/cloud-server.v1.schema.json)保留；处理器明确兼容 1.0.0、1.1.0、1.2.0 和 1.3.0，未知历史契约返回错误。后续正式报价需增加身份、有效期、供应能力与政策确认，不复用后台预览作为订单依据。

## 4. 管理 API 与权限

统一前缀 `/api/admin/v1`，沿用管理员认证 Cookie / Bearer 和 `code/message/data/request_id` 外层。新增写入口要求同源 `Origin`，管理员及操作权限在服务端校验。

| 方法与路径 | 权限后缀 | 用途 |
|---|---|---|
| `GET /cloud-servers/workspace` | `admin.cloud-servers.view` | 概览；仅返回有相应查看权限的统计 |
| `GET /cloud-servers/delivery-rules`、`/delivery-rules/references` | `admin.cloud-delivery-rules.view` | 查询交付规则和安全引用 |
| `POST /cloud-servers/delivery-rules` | `admin.cloud-delivery-rules.create` | 新增交付规则 |
| `PUT /cloud-servers/delivery-rules/{id}` | `admin.cloud-delivery-rules.update` | 编辑与启停，检查 revision |
| `GET /compute-resources` | `admin.compute-resources.view` | 读取类型资源 |
| `POST /compute-resources/{kind}` | `create` | 新增资源 |
| `PUT /compute-resources/{kind}/{id}` | `update` | 编辑资源 |
| `GET /cloud-products`、`/{id}`、`/references`、`/{id}/versions` | `admin.cloud-products.view` | 查询、引用与版本 |
| `POST /cloud-products` | `create` | 保存新草稿 |
| `PUT /cloud-products/{id}` | `update` | 修改草稿 |
| `POST /cloud-products/{id}/publish` | `publish` | 完整校验并封存版本 |
| `PATCH /cloud-products/{id}/status` | `update` | 启停方案 |
| `POST /cloud-products/{id}/preview` | `preview` | `mode=options/price` 联动与计价 |
| `GET /provider-connections`、`/adapters`、`/references`、`/{id}/mappings` | `admin.provider-connections.view` | 连接、可选插件及安全映射资料 |
| `POST /provider-connections` | `create` | 新建禁用连接 |
| `PUT /provider-connections/{id}` | `update` | 修改所选插件配置 |
| `PATCH /provider-connections/{id}/status` | `update` | 启停连接 |
| `POST /provider-connections/{id}/test` | `test` | 认证测试 |
| `POST /provider-connections/{id}/catalog` | `sync` | 读取并缓存指定页目录 |
| `POST /provider-connections/{id}/mappings` | `map` | 绑定已读取的外部资源 |

后缀沿用该行资源的权限前缀。分页默认 10，可切换 20、50、100。销售列表接受 `keyword/page/page_size`；资源与连接表格在前端分页；供应目录使用 `page/per_page`。

现有 `/cloud-products` 的 ID 继续代表销售方案，兼容响应中的 `product_type=cloud_server` 为固定值，前端不展示且产品表不存储该字段。新建方案不增加产品记录。交付规则首期仅支持外部供应商，线路留空表示不额外限定；优先级供后续多规则解析使用，当前不自动调度。

交付规则通过 `resource_ids` 限定地域、可用区、规格组、规格、镜像和存储类型，通过 `line_ids` 限定线路；空数组表示不额外限制。发布及交付预览检查销售资源是否处于规则范围内。“资源对应”在规则表格和供应商页面共用同一组件，并沿用独立的供应查看、目录读取、映射修改权限。

资源映射唯一键为 `connection_id/resource_kind/local_id/scope_zone_id`，0 表示默认对应；同一本地资源可以在不同可用区对应不同外部编号，指定作用域优先。发布时逐可用区校验插件声明的目录及关系，封存 `_zones` 映射；修改当前对应关系不改变已发布版本。没有对应目录的业务参数（例如魔方云的 CPU/内存）作为标准数值交付；地域可从已映射的可用区推导，无需伪造外部地域编号。

销售写入使用 `name/code/description/revision/draft`。发布与启停必须传 `revision`，过期版本返回 409。预览可传 `version_id`；`selection` 仅接受购买配置字段，不接受金额或凭据。

## 5. 魔方云适配范围

新建连接必须选择已安装、启用且兼容的适配器。配置字段和目录种类由所选插件声明，后台不写死供应商选项。已有连接不能切换适配器。魔方云实现位于 `backend/plugins/provider/magic_cloud`，新增适配器遵循 [供应插件 SDK](provider-adapters.md)。

参考本地 `dk-idc/server/app/infrastructure/production/GuzzleMagCloudClient.php` 的协议实现，只参考源码，不导入配置、密钥或业务数据。

- `POST /v1/login` 获取本次调用令牌，后续使用 `access-token`。
- 读取 `areas/nodes/images/stores/ip_groups/image_groups`。
- 内部可用区→`areas`，规格组→`nodes`，镜像→`images`，存储→`stores`，线路→`ip_groups`。
- 只缓存允许的标识、名称及关联元数据，不返回原始上游响应或令牌。
- 10 秒超时，保持 TLS 校验，禁止跟随重定向；地址不接受内嵌账号、查询串或片段。
- 连接配置加密存储。修改地址、账号或密码后，清除测试结论、目录缓存和当前映射；已封存绑定继续保留历史。
- 登录测试成功只证明认证接口可用。能力明确声明 `production_ready=false`、`operations=[]`。

供应商目录读取不会自动创建或覆盖商户资源和销售价格。当前适配器未确认防护能力，包含防护的草稿暂不能发布。具体版本、节点适用范围、网络及磁盘能力须在真实测试环境中核实。
