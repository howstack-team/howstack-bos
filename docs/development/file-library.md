# 统一文件管理

## 范围与入口

内容管理 → 文件管理，后台相对路由 `/content/files`。管理通过系统上传接口登记的公开素材，包含官网、帮助文档、新闻公告和文件库上传；不扫描本地磁盘或云存储桶，也不将私密业务附件暴露在此列表。

统一文件表 file_assets 保存随机文件ID、原始文件名、分类、扩展名、MIME、字节大小、上传来源、管理员ID、时间、存储通道及修订、对象键和状态。对象键不返回后台列表。上传人以原始 `created_by` 管理员ID记录；列表通过批量读取展示当前昵称，昵称为空显示账号，账户缺失显示原ID，不返回密码、手机号或邮箱。上传时固定保存 `channel_id` 和 `channel_revision`，下载和删除只使用这份绑定，不随默认通道切换；后台列表显示上传通道名称，名称为通道当前展示名称，归档后仍可显示。列表不返回存储密钥、桶配置或对象键；通道元数据缺失时显示其原ID。历史图片原始文件名未记录，保持 NULL，由页面明确显示“历史文件”。

## API 与权限

契约：`contracts/openapi/files.v1.yaml`。

| 方法 | 地址 | 权限与用途 |
|---|---|---|
| GET | `/api/admin/v1/files` | `admin.files.view`，分页及多条件查询 |
| GET | `/api/admin/v1/files/statistics` | view，公开文件数量及分类容量 |
| POST | `/api/admin/v1/files` | view + upload，multipart 单文件上传 |
| POST | `/api/admin/v1/files/delete` | view + delete，JSON ids 数组，最多100项 |
| GET | `/api/public/v1/files/{id}` | 公开且成功上传的素材，302受控存储链接 |

默认采用分类侧栏和缩略图网格，提供列表切换；视图、分类、查询和分页保存在 URL。文件管理不展示来源列，也不提供来源筛选，仅使用文件名称和文件类型过滤。容量仅累计 stored 文件的字节数，不代替服务商实时计费用量，不提供目录和回收站。

查询条件：name、type、origin、status、namespace；分页10/20/50/100；大小与时间排序。所有上传先鉴权、再读磁盘和调用默认存储；写入校验同源。可上传 JPG/PNG/GIF/WebP（5MiB、1600万像素）以及 PDF/DOCX/XLS/XLSX/TXT/Markdown/CSV/ZIP/MP4/MP3/SQL/SQLite（20MiB）；扩展名与服务端 MIME 必须一致，拒绝可执行代码、HTML和SVG。DOCX/XLSX 验证主文档类型和 ZIP 结构，限制 3000 项、单项 32MiB、解压总量 64MiB，拒绝加密包、路径穿越和 VBA 内容；XLS 检查 OLE 文件头和工作簿标记。前端图标类型不扩展上传白名单。

## 文件预览

- PDF、DOCX、XLS、XLSX 使用 `@js-preview/pdf`、`@js-preview/docx`、`@js-preview/excel`，按需加载，在 Modal 内展示。图片使用图片预览弹层，音乐和视频也使用 Modal，文件预览不使用抽屉。旧 DOC、PPT/PPTX 不在当前支持范围；加密或损坏文档显示失败提示及下载入口。
- Excel 支持点击选中单元格，上方显示单元格地址和完整内容，并提供复制；预览保持只读。权限刷新复用路由组件，焦点切换不会关闭预览或清空选中状态；访问权限撤销仍按路由权限规则处理。
- Office 样式加载成功后才初始化预览器，避免点击层在未应用样式时测量错误，造成长表格底部无法选中和滚动。浏览器用例延迟 Excel 样式请求并检查点击层完整覆盖；设置 `EXCEL_PREVIEW_NAME` 可额外验证已上传长表格的横向、纵向滚动与滚动后选中，测试不修改该文件。
- Excel 在隔离文档中加载 `DocumentSpreadsheet.css`，为横纵原生滚动条保留 15px 操作区域，避免 macOS 自动隐藏滚动条时退化到 1px。浏览器验收关闭 Playwright 的默认滚动条隐藏参数，并验证实际拖动。
- 文档在禁用脚本的 iframe 内渲染，隔离 Office 样式及活动内容，不执行宏或嵌入 HTML。PDF 字符映射与字体随后台构建交付，与库内 PDF.js 4.7.76 保持匹配，不依赖外部 CDN。
- MP3 音频和 MP4 视频使用西瓜播放器 `xgplayer`，音乐使用同版本 `xgplayer-music`；按需加载、不自动播放。关闭弹窗立即停止播放并销毁播放器。格式能否解码仍取决于浏览器，无法解码时提供下载。
- 音乐预览使用浅色紧凑控制栏、主题色播放按钮与进度，保留原有播放和暂停逻辑；窄屏收起装饰图标，优先保留进度、时间与音量。播放器样式仅作用于音乐预览，视频保留原有外观。
- 使用文件的稳定公开 URL，经绑定的存储通道签名跳转；外部对象存储预览文档需要为后台来源配置 CORS，支持 GET。跨域媒体的分段支持由存储提供者负责。
- 本地签名下载支持单段 `Range: bytes=...`、开放上界和后缀范围，先验签再处理范围，成功返回 206/Content-Range，不可满足返回 416；多段及无效语法忽略并返回完整文件，If-Range 未提供可匹配校验器时返回完整文件。音视频采用 inline 响应。目前宿主存储能力仍完整读取文件再截取响应，上传上限 20MiB，不声明大文件流式读取。
- 上述新增前端依赖采用 MIT 许可证，PDF.js 静态资源遵循 Apache-2.0 并保留包内许可证。

SQL/SQLite文件归入“其他”，支持 `.sql`、`.db`、`.sqlite`、`.sqlite3`。SQL 验证文本 MIME；SQLite 验证 MIME 和文件头，只作为文件存储，不执行 SQL 或导入数据库。列表图片使用真实缩略图，其他文件按后缀匹配图标；“其他”使用 UNTITLED。`20261011000700` 将数据库分类合并回“其他”，保留文件、通道绑定和引用。卡片仅展示缩略图/类型图标及文件名称，大小和通道在列表视图中查看。

## 素材复用与引用保护

官网图片、富文本、Markdown 可从文件库选择已上传图片，保存随机ID或宿主稳定URL，不能保存过期签名URL。保留历史 `/website/images/{id}`、`/content/images/{id}` 图片资源地址。

file_references 按文件、使用范围和对象保存引用；业务保存与引用替换在同一数据库事务内完成。官网、已安装主题、正文均保护引用；临时官网预览在有效期内保护引用。编辑保存前锁定文件并验证状态，删除前锁定同一文件并检查引用，避免引用与删除竞态。更换图片仅解除引用，不自动删除原文件。

删除先整批验证引用，任一项在使用则整批409；再调用上传时的存储通道修订删除对象。确认删除后才软删除元数据并关闭公开URL。部分未确认结果返回 deleted/failed；失败项保留为 delete_failed，可主动重试。进程异常中断留在 deleting 的记录须先人工核对存储状态后处理，不能仅按超时假定删除成功。

## 历史迁移与验收

`20261011000400` 迁入 website_images/content_images，保留文件ID、对象键、上传时间、存储修订和图片URL，回填已有官网、全部主题与正文引用；发现同ID指向不同对象则停止迁移。迁移完成后删除两张旧元数据表，原始存储对象不移动。运行迁移前备份数据库，随后重载后端。

检查全新安装和旧数据升级、禁止删除引用素材、禁止新引用删除中素材、私密文件不可见、上传白名单和只读权限、未确认删除可重试。文件库不声明私密附件或外部桶历史文件已经接入。

图标保存在 `frontend/admin/src/assets/file-types/`，来源及权利信息见同目录 SOURCE.md。
