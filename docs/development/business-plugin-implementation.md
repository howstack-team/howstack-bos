## 2026-10-12：插件入口移至根目录

各类别固定入口直接放在插件根目录，例如 `plugins/sms/aliyun_sms/SmsAdapter.php`、`plugins/provider/magic_cloud/ProviderAdapter.php`。命名空间相应为 `plugins\sms\aliyun_sms`、`plugins\provider\magic_cloud`；不再扫描旧 `api/` 入口。`app/` 仅在需要辅助代码时创建。加载器、23 个内置包、供应商脚手架、测试 fixtures 和开发示例均使用新路径。

前向迁移 `20261012000200_move_business_plugin_entries_to_root.php` 只核准本次内置包的精确旧、新摘要对，同时确认磁盘新包完整摘要匹配。保留版本、启停状态及业务配置，登记 `entry_layout` 审计；已发生其他源码或依赖变化的包不自动审核。仅规范化当前连接中匹配的运行包指纹，不重写订单、任务、发送记录或销售版本的历史快照；配置修订、凭据、测试时间、通道默认选择及归档连接保持原状。

## 已实现

- 业务根目录 `backend/plugins/`，当前实际类别 `provider/mail`，魔方云 ID 保持 `magic_cloud`，内置邮件 ID 为 `smtp`。旧 `backend/plugin/` 已移除；框架 `config/plugin/` 与 Composer 依赖保留。
- 统一 `plugin.json`、配置 DSL、分类及全局 ID 校验、固定命名空间/入口、Core/PHP/SDK 兼容性、包摘要和常见越界依赖检查。单包失败隔离，安全诊断不返回内部路径或原始报文。
- 系统尚未上线，公共协议统一为 v1（清单值 `1.0`）。供应使用固定 DTO、四个方法及可用的受限网络门面；邮件只提供配置校验和发送方法，通过本次配置调用插件本地 Composer 管理的 PHPMailer/HTTP 客户端。所有包执行共同的身份、兼容性和摘要校验；类别方法和网络规则分别定义，不维护旧数组入口或双版本兼容分支。
- 六种配置字段、中文标签、默认值/范围/枚举及未知字段拒绝；供应商多个连接隔离，加密存储，秘密留空保留、显式清除，规范化后再次验证。配置 DTO 的 JSON/调试只返回脱敏标记，禁止序列化进入任务。
- 插件安装、启用、停止接单、停用、审核更新及卸载登记；版本锁与原子事件记录。供应商新增/修改/启用及映射写入先锁安装记录，再锁连接；停止接单后拒绝相关新增写入。
- 停用和更新先检查启用连接，卸载检查所有连接引用。保留历史连接和发布绑定；升级不重算历史摘要，当前连接需要重测。
- 后台独立插件管理菜单、页面和专属前端 API 已移除。应用中心管理已获取应用的安装、更新和卸载；资源连接配置位于“产品管理 → 资源供应商”。本地插件启停等生命周期使用 `php webman business-plugin` 维护，后端固定接口及其细粒度权限、同源写入检查和审计仍由宿主管理，不再注册独立前端路由或角色页面权限行。
- 开发脚手架、无数据库校验命令和受控 CLI 生命周期维护。客户安装只登记已审核本地包，不运行插件脚本或现场编译。

## 后续阶段与限制

- 魔方云目标版本、真实账号及外部目录联调尚待完成；当前不支持生产、续费、重装、释放或退款执行。
- 支付、实名、短信、存储、产品和功能扩展当前只有分类方向，没有可运行 SDK，不会加载为可用渠道。
- 外部写任务、Outbox 消费、结果未知恢复、凭证引用、存量资源续期和可靠排空在第三阶段完成。
- 包上传、解压暂存、签名发布、插件自有数据迁移、依赖协调与多 Worker 热切换还未实现。升级由维护人员部署文件并重启，后台审核当前包。
- 插件本地 Composer 依赖已支持：SMTP 的 PHPMailer 从主依赖移至本插件 `composer.json`、`composer.lock` 和生产 vendor；宿主校验锁定版本、路径及 SDK 冲突后加载。SDK 文件纳入包摘要，修改依赖需审核升级和完整重启。自动隔离不同 SDK 版本仍未实现。
- PHP 插件仍是同进程受信代码；固定 SDK 与静态检查不能替代代码审核，进程、网络及数据库硬隔离单列后续阶段。
- 通用插件级配置、动态前端页面及受控功能扩展点在对应类别交付时建设；当前 provider 配置按连接管理。

开发协议见 [供应插件开发规范](provider-adapters.md)，HTTP 契约见 [后台插件接口](../../contracts/openapi/admin-business-plugins.v1.yaml)。
