# 更新记录

## 1.5.0

- 增加可选 VNC 契约，核验原实例 ID 与主机名后获取安全 WSS 连接。
- 仅向宿主返回 VNC 地址和认证密码，过滤系统登录密码及第三方页面地址。
- 新控制台连接支持经审核的同 ID 插件升级，保留原连接、资源身份与历史任务约束。
- 协议及权限测试已通过，真实平台 WSS、证书和 Origin 仍需联调。

## 1.3.0

- 增加可选生命周期契约，自管资源续费确认、到期暂停和恢复。
- 按原实例 ID 与首次主机名核验；操作后只查询，不将受理当作完成。
- 清单增加受限正整数 ID 路径模板，不开放任意端点。
- 协议测试通过；真实平台联调仍需单独验收。

## 1.1.0

- 从旧应用插件目录迁至分类业务插件目录，插件 ID 保持 `magic_cloud`。
- JSON 清单与连接配置声明分开，安装启停由宿主记录管理。
- 使用供应 SDK v1 DTO、固定入口与受限 HTTP 服务。
- 保留认证、只读目录及关系校验；真实生产能力保持未开放。
- SDK、包摘要变化后存量连接须重测；历史绑定保留原版本。
