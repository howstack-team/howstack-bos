# 魔方云资源对接插件

包版本 `1.1.0`，公共供应 SDK `1.0`。在“系统管理 → 插件管理”审核安装、启用后，在“产品管理 → 资源供应商”选择魔方云，填写平台地址、登录账号和登录密码，保存后显式测试，再启用供应商。

当前实现 v1 登录认证、可用区/节点/镜像/存储/IP 组目录查询及绑定校验，不支持资源生产、续费、释放或资金操作。没有经过指定版本真实平台联调；模拟 HTTP 测试不等于生产接入完成。

一个插件可以关联多个供应商，凭据各自加密保存。固定方法只依赖公共 SDK 和宿主受限 HTTP 门面；不能访问核心模型、容器或原始网络客户端。包目录不保存真实地址、秘密或运行日志。

目录为 `backend/plugins/provider/magic_cloud/`，声明在 `plugin.json` 与 `configuration.schema.json`；不使用 Webman 应用插件配置。代码/清单变化后重新审核安装记录，启用后重测供应商，原历史绑定不覆盖。

详情见 [供应 SDK 与生命周期](../../../../docs/development/provider-adapters.md)。
