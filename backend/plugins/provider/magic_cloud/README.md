# 魔方云资源对接插件

包版本 `1.5.0`，供应 SDK `1.0`，PHP 最低 `8.3`。通过受审核应用安装流程启用，配置独立供应连接并测试后使用。

实现连接测试、资源目录、映射校验、逐实例创建/查单，以及自管资源续费确认、到期暂停和恢复。底层资源的销售期限由本系统管理，此插件不会创建或支付第三方订阅续费单。创建使用固定主机名，所有生命周期操作同时核对原 ID 与主机名。

连接和插件摘要随首次供应任务固定；更换插件或凭据不自动改变存量任务目标。代码或清单变更必须重新审核，不能直接覆盖历史摘要绕过保护。未知操作结果只查单，不重复提交。

当前已通过模拟 HTTP 协议和隔离数据库验证，未完成目标魔方云版本的真实平台联调。使用前需对照已安装魔方云后台 API 文档确认字段及暂停/恢复状态。

支持可选 VNC 远程控制台契约：核验原实例身份后签发直接 WSS 地址和 VNC 密码，不回传系统登录密码。新 VNC 连接使用当前审核通过的同 ID 插件；原供应连接与实例身份保持固定，不改变既有任务的包摘要约束。浏览器须能直接访问供应商 WSS 网关，详见[远程控制台](../../../../docs/development/cloud-vnc-console.md)。

详见[续费与到期处理](../../../../docs/development/service-renewal-and-expiry.md)和[供应 SDK](../../../../docs/development/provider-adapters.md)。
